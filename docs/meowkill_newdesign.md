## 三、游戏规则

### 1. 核心概念

**体力与手牌上限**
- 初始体力：除家猫4点外，其余均为3点。
- 手牌上限 = 当前体力值。
- 体力归零 → 出局，亮明身份牌。
- 击杀奖励：当一名野猫出局时，击杀者获得其所有手牌。

**攻击范围**
- 默认攻击范围：**左右相邻各1名玩家**（共2人）。
- 玩家座位在游戏开始后固定，不可随意更换。

**回合流程（三步走）**
```
① 摸牌阶段   摸2张牌（橘猫摸3张）
② 出牌阶段   可使用至多1张【抓挠】+ 任意张喵叫牌/装备牌
③ 弃牌阶段   手牌数 ≤ 当前体力值
```

---

### 2. 卡牌使用细则

**使用【抓挠】**
- 每回合限1张。
- 必须对**攻击范围内**的玩家使用（装备【毛线球】后可全场攻击）。
- 目标可打出【闪躲】抵消。
- 【炸毛】可让下一张【抓挠】伤害+1。
- 狸花猫限定技：抓挠需2张【闪躲】才能抵消。

**使用【闪躲】**
- 仅在成为【抓挠】目标时可以打出。
- 白猫可以用任意手牌代替【闪躲】。
- 【咬咬】不可被【闪躲】抵消。

**使用喵叫牌**
- 无次数限制，出牌阶段可连续使用。
- 英短的“迟钝”技能会使喵叫牌效果减半（向下取整）。

**使用装备牌**
- 出牌阶段打出，放在面前。
- 已有一件装备时，新装备会顶替旧装备（旧装备弃置，不可回收）。

---

### 3. 特殊规则说明

**英短“迟钝”技能判定**
- 被【逗猫棒】指定：对方抽0张牌（1÷2=0.5，向下取整=0），即免疫。
- 使用【小鱼干】：回复0点体力（1÷2=0.5，向下取整=0），小鱼干浪费。
- 被【咬咬】指定：伤害0（1÷2=0.5，向下取整=0），对方仍需弃1张牌。

**布偶猫“威吓”技能判定**
- 仅在被【抓挠】指定时触发。
- 展示手牌如果包含【闪躲】，该【抓挠】无效（不消耗展示的【闪躲】）。
- 展示后，对方已用掉的【抓挠】不会退回。

**独行猫结算**
- 若家猫被**非独行猫**击杀，独行猫立即失去胜利资格。游戏继续，但独行猫无法获胜。
- 独行猫击杀家猫后，仍需存活至**场上只剩自己**才算获胜。
- 独行猫击杀家猫后身份暴露，将成为所有人目标。

## 四、游戏准备与开局

### 步骤
1. **坐定**：所有玩家围坐，决定座位顺序。
2. **发身份牌**：按人数取用身份牌，洗混后每人暗抽1张。家猫拿到身份后亮明。
3. **发猫种牌**：8张猫种牌洗混，每人暗抽1张，查看后扣置于面前。
4. **设置体力**：家猫4条🐟，其余3条🐟。
5. **发起始手牌**：每人从牌堆摸3张。
6. **开始游戏**：家猫左手边玩家开始，顺时针进行。

## 五、进阶策略指南

### 各身份玩法要点

**家猫**
- 你是明牌，有4血优势，可以打得稍微激进。
- 留意谁疯狂打你（野猫嫌疑），谁拼命保你（可能是同伴，也可能是独行猫在演戏）。
- 不要轻易把独行猫当同伴——他帮你清野猫是为了亲手杀你。

**同伴猫**
- 你的命=家猫的命，但别暴露太早。
- 用【逗猫棒】试探、用距离限制掩护家猫侧翼。
- 必要时替家猫挡刀，但别无意义送死。

**野猫**
- 目标是家猫的命，不是杀光全场。
- 前期低调，假装帮家猫清“野猫”，转移嫌疑。
- 集火家猫的时机很重要——等他手牌消耗差不多时出手。

**独行猫**
- 最考验技术的身份。
- 前期必须保住家猫不被野猫杀死，否则直接输。
- 中期帮家猫清野猫，建立信任。
- 后期找机会亲手击杀家猫，然后单挑残局。
- 最佳节奏：剩你、家猫、另一只残血猫时动手。

### 各猫种操作建议

| 猫种 | 打法偏向 |
|:---|:---|
| 橘猫 | 稳定收益型，多摸牌=更多选择，适合新手 |
| 黑猫 | 卖血换牌，故意吃小伤害积攒资源 |
| 白猫 | 铁壁防守，任何牌都是闪，很难被强杀 |
| 暹罗猫 | 信息控制，多看牌判断身份和手牌结构 |
| 英短 | 抗干扰，不怕逗猫棒和咬咬，专注攻防 |
| 布偶猫 | 条件无敌，手里有闪=物理免疫，威慑力强 |
| 狸花猫 | 一击必杀，限定技留给关键目标（家猫/残血） |
| 无毛猫 | 爆发型，一回合两抓可以强行秒人 |

## 六、DIY制作指南

### 卡牌制作
- **尺寸**：标准扑克牌 63mm×88mm，或用空白卡牌DIY。
- **牌背**：统一猫爪图案。
- **正面**：牌名 + 效果文字 + 简笔画图标。
- **角色牌**：猫种名称 + 技能描述 + 猫咪插画。
- **身份牌**：只印身份名，背面统一。

### 体力标记
- 推荐用小零食（如旺仔小馒头、小鱼干）或硬币。
- 失去体力=吃掉或移走一枚。

### 装备标记
- 打出装备牌后直接放在自己角色牌旁边，清晰可见。

## 七、变体规则（可选）

### 1. 换座规则
每局限一次，出牌阶段可支付1张手牌，与任意玩家交换座位。
> 增加位置博弈深度。

### 2. 双猫种模式
6人局可选：每人抽取2张猫种牌，选择其中1张使用。
> 增加角色搭配乐趣，但会提高复杂度。

### 3. 快速模式
起始手牌5张，家猫体力3（无加成）。
> 适合想10分钟内结束的场合。

## 八、常见问题 FAQ

**Q：【猫爬架】和【布偶猫】技能冲突吗？**
A：先结算【猫爬架】（对方需弃牌才能指定你），对方弃牌指定你后，你再决定是否触发布偶猫的“威吓”展示手牌。

**Q：无毛猫一回合出2张【抓挠】，可以给同一人吗？**
A：可以。

**Q：没有手牌时，能被【逗猫棒】抽吗？**
A：不能，【逗猫棒】目标必须有至少1张手牌。

**Q：独行猫击杀家猫后，被野猫反杀，野猫赢吗？**
A：是的。家猫已出局，野猫的胜利条件“家猫出局”已达成，野猫获胜。（即使独行猫先死）
