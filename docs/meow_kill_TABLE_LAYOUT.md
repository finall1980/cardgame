# 猫猫杀 · 游戏桌面布置设计

**版本**：v0.1  
**依据**：参考经典身份类桌游「围桌 + 中央出牌区 + 下方本家」的信息层级；你提供的 8 人局截图体现 **U 形 / 环状排座** 与 **中央大画幅** 用于打出牌与技能演出。

---

## 1. 设计目标

| 目标 | 说明 |
|------|------|
| **可读性** | 当前回合、阶段、响应倒计时集中在 **中下部** 与本家附近，避免视线在角落来回跳。 |
| **可扩展** | **5 人（M1 默认）** 与 **8 人** 共用同一套「方位枚举 → 控件槽位」映射，仅换 `seat → slot` 表。 |
| **与素材一致** | 手牌用大图 `meowkill/big-card`；桌面打出/结算用 `meowkill/card`；武将为 **框 + 势力 + 肖像** 拼接（见 `MeowKillGeneralAssets`）。 |

---

## 2. 屏幕分区（逻辑层）

以 **16:9 横屏** 为基准，逻辑分区如下（比例可随 `Control` 锚点微调）：

```
┌─────────────────────────────────────────────────────────────┐
│  TopHUD  (~8% 高)   身份统计 · 轮次 · 计时 · 牌堆剩余        │
├─────────────────────────────────────────────────────────────┤
│         ┌── TopRail：对家/上家方向一排头像槽 ──┐              │
│  Left   │                                     │   Right      │
│  Rail   │     CenterPlay：打出牌/锦囊/技能      │   Rail       │
│  竖条   │     动画、飘字、询问条、无懈插入提示   │   竖条       │
│         └─────────────────────────────────────┘              │
│  BottomSelf (~22–28% 高)：本家手牌扇形 + 己方武将 + 操作按钮  │
└─────────────────────────────────────────────────────────────┘
```

- **TopHUD**：与参考图一致，左上角 **剩余身份分布**（主忠反内数量）；右上 **局时/轮次**；可选 **观战数**、菜单。  
- **CenterPlay**：视觉焦点；打出牌用大贴图居中略偏上；技能台词/特效叠在牌上方或全屏淡入。  
- **BottomSelf**：**手牌区**（左下至中下，重叠扇出）；**己方武将** 常在 **右下**（与参考图一致：大肖像 + 竖排体力珠 + 手牌上限 `手牌数/体力`）；左下为 **记录 / 排序** 等。  
- **LeftRail / RightRail / TopRail**：摆放 **其他玩家** 的「竖条头像」组件（小肖像 + 体力点 + 手牌张数角标 + 状态边框高亮）。

---

## 3. 座位 → 屏幕槽位（5 人局，M1）

约定 **逻辑座位** `0..4` 为服务端顺序；**视觉本家**始终映射到 **BottomSelf 正对方向**，其余座位按逆时针铺在环上。

推荐映射（`self_seat` 为本机座位）：

| 相对座位 `d = (seat - self_seat) mod 5` | 屏幕区域 | 备注 |
|----------------------------------------|----------|------|
| 0 | **BottomSelf** | 本家：大手牌 + 大武将 |
| 1 | **RightRail 中下** | 下家（右手边） |
| 2 | **TopRail 靠右** | 对侧偏右 |
| 3 | **TopRail 靠左** | 对侧偏左 |
| 4 | **LeftRail 中下** | 上家（左手边） |

效果：**上沿两人、左右各一人、下为自己**，中央留白出牌 —— 与 5 人「小圆桌」直觉一致。

实现：在 Godot 中用 `TableSlots` 容器预先放 5 个 `Marker2D` 或 `Control` 锚点，`bind_seat(self_seat)` 时只调整各槽 `visible` 与 `modulate`，不必改子节点层级。

---

## 4. 座位 → 屏幕槽位（8 人局）

参考你提供的 8 人布局：**顶部横向容纳多名对手**，**左右各一竖列**，**本家在底部**（手牌 + 武将），**中央**为牌面与特效。

推荐映射（`d = (seat - self_seat) mod 8`）：

| d | 区域 |
|---|------|
| 0 | BottomSelf（本家） |
| 1 | 右侧竖条偏上（「右肩」位） |
| 2..6 | **TopRail** 从左到右 5 个槽（或 4+1 微调避免拥挤） |
| 7 | 左侧竖条偏上（「左肩」位） |

8 人时 **TopRail** 需 **更窄的单卡宽度** 与 **略小的头像比例**；必要时开启 **横向滚动** 或 **两行错位**（上排 3 + 下排 2），以 720p 仍可读为底线。

---

## 5. 单玩家「竖条」组件信息（与参考图对齐）

每个非本家槽位建议包含（自上而下 / 自外向内）：

1. **势力角标**（魏蜀吴群神）  
2. **角色名**（短文本省略）  
3. **身份标记**（主忠反内：仅自己可见真身时隐藏他人具体身份，可用问号或「已亮将」状态）  
4. **竖排体力珠**（与参考图一致，比横条更省宽）  
5. **手牌背张数**（数字角标）  
6. **装备区缩略**（M2+：武器/马小图标）  
7. **状态框**（`compact/frame/responding.png` 等）  
8. **思考中 / AI**：`is_ai` 时显示「牌手」或机器人角标（与匹配 10s 补位体验一致）

**当前行动高亮**：槽位外框发光或 `playing.png` 叠加（素材已在 `meowkill/compact/frame`）。

---

## 6. 本家区细节

- **手牌**：横向重叠，`expand_mode` 与掼蛋类似；可选「牌序」按钮。  
- **阶段条**：在 **手牌上方** 显示「出牌阶段」「弃牌阶段」等（参考图蓝色条）。  
- **技能按钮**：M2+ 在武将旁或手牌上方弹出；M1 可仅占位。

## 8. 后续迭代

- **分辨率适配**：用 `SubViewport` 缩放手牌区 vs 用纯锚点；平板竖屏另做 `layout_portrait`。  
- **技能演出时间轴**：中央区队列（牌 → 伤害数字 → 台词），避免与多目标询问叠在一起。  
- **无障碍**：色觉友好身份描边 + 文字不全依赖颜色。
