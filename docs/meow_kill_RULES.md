## 1. 游戏目标（身份局）

每名玩家秘密（或按规则公开）持有一张**身份牌**，胜利条件由身份决定。常见四种身份如下（与公开身份局说明一致）：

| 身份 | 胜利条件（摘要） |
|------|------------------|
| **主公** | 消灭场上所有**反贼**与**内奸**。 |
| **忠臣** | 与主公相同。主公死亡则忠臣失败（除非规则另有立即结算分支）。 |
| **反贼** | **主公**死亡时反贼阵营获胜（具体以规则集「主公死亡时结算」为准）。 |
| **内奸** | 需在**仅剩内奸与主公**等规则规定的单挑局面下杀死主公方可获胜；若主公死亡时仍有其他阵营角色存活，内奸不获胜（详见规则集濒死/死亡与游戏结束章节）。 |

**主公公开**：游戏开始时主公身份通常**亮出**；其余身份保密至死亡亮出或技能要求展示。

**主公体力**：主公选用武将后，体力上限通常 **+1**（与标准身份局一致，具体以选用武将牌与规则集为准）。

## 3. 游戏区域与牌堆（概念）

与规则集一致的核心区域包括（名称以规则集为准）：

- **牌堆** / **弃牌堆**
- **每名角色**：**武将牌**、**体力**、**手牌**、**装备区**（武器/防具/进攻马/防御马）、**判定区**（延时锦囊等）

**游戏牌**大类通常包括：

- **基本牌**（如【杀】【闪】【桃】等）
- **锦囊牌**（非延时 / 延时）
- **装备牌**

具体牌名、数量、效果以你们选定的「规则包」清单与规则集「游戏牌」章节为准。

---

## 4. 回合结构（标准六阶段）

每名角色一个回合，从**主公**开始按逆时针进行。标准流程分为六个阶段（与 [国战公开说明](http://guozhan.sanguosha.com/game_rule/game.html) 等处对「六阶段」的表述一致，身份局亦同框架）：

1. **回合开始阶段**  
2. **判定阶段**（判定区有延时锦囊时依次判定；多张时**先判定后放置的**——即「后进先判」的常见规则）  
3. **摸牌阶段**（通常摸 **2** 张）  
4. **出牌阶段**（可使用若干牌；通用限制见下）  
5. **弃牌阶段**（手牌数超过当前体力则弃至等于体力）  
6. **回合结束阶段**

**出牌阶段常见通用限制**（技能与装备可修改）：

- 通常每阶段仅可使用 **1** 次【杀】（【诸葛连弩】等可突破）。
- 同一角色判定区内**不能**有两张**同名**延时锦囊。

**技能优先级**（原则性）：当技能与基本规则冲突时，**以技能描述为准**（规则集「技能」「结算原则」中有更细的时机与冲突处理）。

---

## 5. 距离与【杀】的目标

- **攻击范围**默认 **1**（仅可对左右相邻座位使用【杀】，除非被 +1 马、-1 马、武器等改变）。  
- 具体距离计算与「马」的叠加规则以规则集「距离」专题为准。

---

## 6. 伤害、濒死与死亡

1. **体力扣减**至 0 或更低 → 进入**濒死**，从当前回合角色开始通常按逆时针询问是否使用【桃】等。  
2. **死亡**：亮出身份牌，弃置其所有牌（手牌、装备、判定区牌等），然后结算**奖惩**（见下）。  
3. **击杀奖励**：**凶手杀死反贼**通常立即摸 **3** 张牌（若凶手身份与规则集条文有额外限制，以实现锁定版本为准）。  
4. **主公杀死忠臣**：主公须**弃置所有手牌与装备**（公开规则常见条文）。

游戏是否在此时立即结束，依「主公死亡 / 反贼与内奸全灭」等条件判定，详见规则集「游戏结束」流程。

---

## 7. 选将流程（摘要）

标准身份局常见流程（细节以规则集与你们选定的模式为准）：

1. **主公**先选将：常见为主公从若干张候选武将中选 **1**，并亮出。  
2. 其他玩家从发到的候选中将中选 **1**，同时亮出武将。  
3. 确定座位、起始手牌（常见每人 **4** 张起始手牌）、牌堆与第一个回合行动者（主公）。

「猫猫杀」可将武将命名为猫猫角色，但**技能时机与效果**须与所选规则包一致或可配置。

## 8. 与实现相关的「必须写进设计」的规则点

以下若未在服务端严格实现，容易出现线上争议：

- **时机与队列**：使用牌、打出牌、判定、移动牌、伤害事件的**先后顺序**（规则集「事件、响应与结算」）。  
- **无懈可击**的插入结算与「锦囊目标」定义。  
- **装备替换**、武器距离、坐骑与距离的叠加。  
- **牌堆抽空**：重洗弃牌堆的时机与顺序。  
- **同时机技能**的优先级（规则集「锁定技与优先级」等专题）。
